## Home Screen shortcuts

Long-press an imported game cartridge in the launcher and choose the Home
Screen action. For custom carts, open Custom Carts and use Home Screen on the
cart row you want. iOS opens a configuration profile in Safari; approve it
from Settings when prompted. The generated entry keeps the game's or cart's
artwork and launches through the same `gen1recomp++://launch` URL format; see
[launch options](../guides/launch-options.md).
